# EDUVIA — تطبيق وليّ الأمر (PWA) · دليل التشغيل والنشر

تطبيق وليّ الأمر أصبح **PWA قابلًا للتثبيت** على الهاتف (يعمل دون إنترنت بعد التثبيت).

## 1) تجربة التثبيت على حاسوبك الآن
الخادم المحلي يعمل. افتح في Chrome/Edge:
```
http://localhost:8080/parent-app.html
```
- سيظهر زر **«⬇️ تثبيت التطبيق»** داخل الإطار، أو أيقونة تثبيت في شريط عنوان المتصفّح.
- لإعادة تشغيل الخادم لاحقًا: من داخل مجلّد `smart-school-demo` نفّذ:
```
node serve.js
```

## 2) تجربته على هاتفك / نشره للأولياء  ⚠️ يتطلّب HTTPS
التثبيت وService Worker يعملان فقط عبر **HTTPS** (أو localhost على نفس الجهاز).
فتح التطبيق على الهاتف عبر `http://192.168...` **لا يكفي** (ليس آمنًا). لذلك ارفعه على استضافة HTTPS مجانية:

### الأسهل — Netlify Drop (بلا حساب تقني)
1. اذهب إلى: https://app.netlify.com/drop
2. **اسحب مجلّد `smart-school-demo` كاملًا** وأفلته في الصفحة.
3. تحصل فورًا على رابط HTTPS مثل: `https://eduvia-parent.netlify.app/parent-app.html`
4. أرسل الرابط للأولياء → يفتحونه → «إضافة إلى الشاشة الرئيسية».

> بدائل: **Vercel** أو **Cloudflare Pages** أو **GitHub Pages**، أو استضافتك الخاصة على نطاق `eduvia.dz`.

## 3) للنشر على Google Play (لاحقًا)
حوّل الـPWA إلى حزمة APK عبر **PWABuilder.com** (يقرأ الرابط وينتج APK جاهزًا للمتجر) — تحتاج حساب مطوّر Google Play (25$ لمرة واحدة).

## ملفات الـPWA
- `manifest.json` — هوية التطبيق والأيقونات
- `sw.js` — التخزين المؤقت والعمل دون إنترنت
- `icons/` — أيقونات 192/512/maskable + apple-touch
- `serve.js` — خادم محلي للتجربة فقط (لا يُرفع للاستضافة، اختياري)

## ملاحظة
البيانات حاليًا تجريبية داخل التطبيق. النسخة الحقيقية تتصل بخادم المؤسسة لجلب بيانات الطفل الفعلية.
